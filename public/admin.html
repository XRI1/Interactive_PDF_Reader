Switches → country → abstract

Each switch flies the map to its place, then shows the abstract of its PDF with a QR code for download. PDF “Auto” picks the file whose name starts with the switch number (1_…, 2_…). Abstract “Auto” finds the part between “Abstract” and “Introduction”; if it picks the wrong part, choose a page number instead. On the player, keys 1–9 and 0 act like the switches.
